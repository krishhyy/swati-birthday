# Swati Birthday Experience

A lightweight interactive birthday website using the original photos and birthday audio.

## Run
Open `index.html` directly or deploy the folder to Netlify/GitHub Pages.

## Customize
- Main photos: `images/1.jpeg`, `images/2.jpeg`, `images/3.jpg`
- Paper photos: `images/s1.jpg`, `images/s2.jpg`, `images/s3.jpg`
- Background assets: `images/bg1.jpg` / `images/bg2.jpg`
- Music: `audio/birthday.mp3`
- Text and interactions: `index.html` and `script.js`
